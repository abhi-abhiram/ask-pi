π Ask pi

Select text on any page, then click the π button or press Alt+Shift+A. Your question goes to the pi harness running on this computer.

Connect to pi

  1. Download the bridge and start it in a terminal (Node 18+ and pi on your PATH): 
    curl -fsSLO https://raw.githubusercontent.com/abhi-abhiram/ask-pi/main/bridge/pi-bridge.mjs
node pi-bridge.mjs

    The bridge is a single dependency-free file. Read it first if you like: github.com/abhi-abhiram/ask-pi

  2. Copy the token it prints and paste it below.
  3. Choose Test connection.

Also saved at ~/.pi-ask-bridge-token. It stops other websites from using your pi through localhost.

Turn this off to use only the keyboard shortcut or the right-click menu. Change the shortcut at chrome://extensions/shortcuts.
